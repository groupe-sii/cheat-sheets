# Collaboration QA/Dev/Ops
| Pratique Collaborative   | Description                                  |
| ------------------------------------------ | -------------------------------------------- |
| **Pilotage mutualisé et commun**| Dashboards/KPI de test accessibles à tous|
| **Revue collective des US**| Approches 3Amigos|
| **Stratégie de test collaborative**| Notamment approche BDD piloté par les tests|
| **Test-as-Code**| Test stocker dans le même dépôt que le code et accessible aux développeurs|
| **Shift Left**| Intégration des tests QA dans les phases d'intégration |
| **Tester en continu via les pipelines CI/CD**| Intégration des tests dans chaque branche / pull request|
| **Suivi opérationnel de la QA**| Recherche des Test Flaky, Fiabilisation des exécutions|

| **Observabilité Shift Right**| Testeur impliqué dans l’analyse des incidents production|


# Pipeline TestOps
1.🔨 Build: Compilation, Validation statique (lint, SonarQube, etc.)  
2.🚀 Deploiement: Déploiement automatisé dans un environnement de test ou de staging  
3.🤖 Automatisation de Test: Test unitaire/Test d'Intégration/Test E2E/Test Opérationnel  
4.📡 Monitor: Surveillance des logs, erreurs, temps de réponse, données de test  
5.🔁 Feedback: Dashboards, alertes, notifications
