**Robot Framework** est un framework open source d’automatisation de test basé sur une **approche déclarative** par mots-clés (**keyword-driven**). Il est particulièrement adapté :
- aux **tests de regressions fonctionnels**, 
- aux **tests d'API**, 
- aux **tests web**, 
- aux **test d'acceptance tests collaboratifs**, 
- et au **RPA**.

# Caractéristiques clés
- 📚 Langage naturel structuré : fichiers de test en format table (robot, .txt, .tsv)
- 🧩 Architecture modulaire : riche écosystème de bibliothèques (standard et tierces)
- 💬 Lisibilité métier : syntaxe claire utilisable par des profils non développeurs
- 🔁 Extensible : plugins Python, Java, ou via des outils tiers
- ⚙️ Automatisation web/API/desktop/base de données
